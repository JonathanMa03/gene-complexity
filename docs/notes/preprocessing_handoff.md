# Message to the preprocessing teammate

Could you prepare one versioned downstream dataset with the following handoff? Please coordinate scGPT-specific inputs with its owner before finalizing the source.

1. **Establish the original data source and count provenance.** Keep the downloaded file unchanged and record its URL/accession, version, checksum, and existing processing. Our current Pancreas file uses gene symbols, and its `counts` layer has fractional values that the scGPT extractor rejects. Please investigate or obtain verified raw counts; do not round values or assume a layer name guarantees raw counts.
2. **Preserve identifiers and metadata.** Assign stable unique cell IDs; retain original IDs, cell-type labels, technology, and available donor/study IDs. Establish a documented gene-symbol-to-unversioned-Ensembl mapping for scGPT, preserving symbols for interpretation. Report ambiguous/unmapped genes and how duplicates are handled; don't silently drop them.
3. **Agree on the common cell population.** Document QC rules and all excluded cell IDs/reasons. Check scGPT panel coverage and cells with zero panel expression with its owner. Ensure all three comparisons use the same retained cells. Separate technical QC from learned thresholds; fit data-dependent thresholds on training data where applicable.
4. **Create one shared split manifest before feature fitting.** Export `cell_id`, `celltype`, and `split` (`train`, `validation`, `test`), plus available group metadata. Agree on fractions and seed; prefer study/donor grouping when appropriate, and check label coverage in each split. Technology is not donor identity. Record rare/unseen-class handling explicitly, without changing splits to improve model results.
5. **Provide two compatible feature paths.** Preserve verified raw counts with Ensembl annotations for scGPT's fixed panel and its own binning. Separately provide documented normalized/log-transformed classical expression for dictionary learning and the raw-expression classifier baseline. Agree on library-size normalization, variable-gene selection, and scaling. Fit gene selection/scaling on training cells only; apply the same fitted transformations and ordered gene set to validation/test. Don't standardize scGPT inputs with the classical pipeline. For later cross-validation, these fitted steps must be repeated within each training fold.
6. **Export a reproducible bundle.** Include raw-count AnnData; classical feature matrices with ordered cell and gene IDs; the split/label CSV; fitted preprocessing parameters; gene mapping and exclusion tables; and a short JSON/README containing source hashes, settings, seeds, software versions, shapes, and panel coverage. Keep large data outside Git and provide a reproducible script/download route. Use sparse matrices where useful and avoid unnecessary full-matrix densification.
7. **Check the handoff.** Verify unique IDs, finite features, matching row IDs across feature paths, identical gene ordering across splits, disjoint split membership, and available group separation. Coordinate pretraining-overlap auditing with scGPT's owner; missing Census/study metadata does not prove independence.

For dictionary learning I need a training matrix to fit the dictionary, validation/test matrices to encode using that fixed dictionary, and ordered cell/gene IDs. The classifier teammate needs each representation joined by cell ID to the shared labels and splits. No independent reshuffling or separate splits inside model branches.

The synthetic dictionary baseline is an interface demonstration only; its centering and toy splits do not prescribe the final biological preprocessing.
